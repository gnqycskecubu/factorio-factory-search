## Overview

Factory Search adds a global search overlay that finds any entity, item name, or recipe in your factory and jumps the camera to matching results, eliminating the hunt for that one mislabeled chest.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Factory Search** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Entity Search** | Find any building or chest by name across the entire map |
| **Item Finder** | Locate storage containing a specific item in one keypress |
| **Recipe Lookup** | Search ingredients and locate all machines producing a given item |
| **Jump Navigation** | Click a result to instantly center the camera on that entity |
